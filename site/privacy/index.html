Policy / 27 August 2026

Privacy, in plain type.

Code Proof is local software. Your Markdown and PDF documents are not sent to us.

CLI data

The CLI has no account, analytics, telemetry, advertising, crash upload, or network API. It reads the paths you provide, may start the renderer you select, and writes the PDF and proof artifacts locally. A custom renderer remains subject to its own behavior.

Website data

This documentation site does not use cookies, tracking pixels, third-party fonts, or analytics scripts. Standard server access logs may temporarily contain an IP address, request path, user agent, and timestamp for security and operations.

Storage and control

The site service worker caches public documentation assets on your device for offline use. Clear the site’s storage in your browser to remove them. CLI artifacts remain wherever you direct the command and can be deleted normally.

Questions

Open an issue in the public source repository for privacy questions or corrections.
