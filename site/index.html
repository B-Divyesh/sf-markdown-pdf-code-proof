How it works

Check the source against the PDF.

Code Proof compares your Markdown with the finished PDF. It writes an HTML proof sheet for review.

  1. 01

    Create or choose the PDF

    Check an existing PDF, or use a custom renderer command. Renderer arguments never pass through a shell.

  2. 02

    Check the finished PDF

    Check links, code colors, and text that runs outside the page. Match each code fence with the PDF.

  3. 03

    Review the result

    Open the HTML proof sheet, save a JSON report in CI, and use exit codes to stop a broken release.

Install

Add Code Proof to your build.

Install from the public repository with Rust 1.88 or newer. Then check a Markdown and PDF pair.

Read the full CLI reference ↗
01 / installcargo install --git https://github.com/B-Divyesh/sf-markdown-pdf-code-proof.git --locked codeproof
02 / checkcodeproof check manual.md --pdf manual.pdf
03 / CIcodeproof check manual.md --pdf manual.pdf --json

Renderer safety

Linux renderer commands cannot use network sockets.

Code Proof runs a renderer only after Linux sandbox setup succeeds. Checking an existing PDF does not start a renderer.
